# Live USDT/IRT Price — TradingView Watchlist

<img width="1838" height="900" alt="usdt-irt-price-in-tradingview-extention" src="https://github.com/user-attachments/assets/b5d7a44c-cfcd-45b8-a1e3-9e497c0b226b" />



A Chrome extension that displays the **live USDT price** inside the TradingView Watchlist.

The price is received from the **ArzDigital live socket** using the Centrifugo protocol on channel `price:812`.

After installation, a sleek dark strip is added to the TradingView Watchlist widget. It displays the USDT price in tomans, the 24-hour change, connection status, and the latest update time.

Whenever the price changes, the strip flashes green or red, just like TradingView.

## Installation

1. Open this folder and make sure that `manifest.json` is located next to the other files.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select this folder.
5. Open a TradingView tab. The USDT price strip will appear below the Watchlist header.

> **Tip:** To test the socket without Chrome, run `node scripts/test-ws.js`.
> This requires Node.js 21 or later. To test the parser, run `node scripts/test-parser.js`.

## How It Works

1. `content.js` opens a WebSocket connection on every TradingView page:

   `wss://ws.arzdigital.com/connection/websocket`

2. It performs the Centrifugo handshake:

   ```json
   {"id":1,"connect":{}}
   ```

   Then it subscribes to the USDT channel:

   ```json
   {"id":2,"subscribe":{"channel":"price:812"}}
   ```

3. Every 25 seconds, it sends `{}` as the protocol heartbeat. The server ping interval is 25 seconds.
4. It parses push messages. The price is read from the `pirt` field, which contains the price in tomans. Other available fields include:
   - `pusd`: USD price
   - `p24h`: 24-hour change
   - `mc`: market capitalization
   - `v`: volume
5. The price strip is updated, and the latest price is sent to the popup through `chrome.runtime`.
6. If the connection is lost, it reconnects automatically using exponential backoff from 1 second up to 30 seconds.

## About the Two Issues Discussed

### Issue 1 — Hashed CSS Selectors

TradingView class names are generated by CSS Modules and may change with every build, for example:

```css
.listContainer-LVUu4GCH
```

Instead of relying on hashed class names, the extension uses a stable attribute:

```js
document.querySelector('[data-test-id-widget-type="watchlist"]')
```

This attribute is stable in the TradingView HTML and is more reliable than the shortened selector:

```css
[class*="listContainer"]
```

### Issue 2 — Virtualized List

The Watchlist rows are virtualized. They use `position: absolute` and are positioned with `top`, while only the currently visible rows exist in the DOM through `react-window`.

As a result, any node added inside the `listContainer` may be removed by React during scrolling.

**Solution:** Instead of fighting the virtualized list, the price strip is injected **after the widget header**, at the `widgetbar-widget` level. This location is not managed by the virtualized list framework.

Visually, the strip appears like a row at the top of the list and is re-injected when necessary using a `MutationObserver` if TradingView re-renders the widget.

## Why Did the Price Previously Show `—`?

There were two common causes:

1. **Splitting frames only by `\\n`:** In the real socket logs, multiple JSON objects may arrive consecutively without a newline, for example:

   ```text
   }} {"push":{...}}
   ```

   Splitting only on newlines therefore fails. This extension separates complete frames by counting braces while correctly handling braces inside strings.

2. **Using the wrong field:** The tomans price is stored in `pirt`, not `d`. A live test using `test-ws.js` confirmed a value such as `pirt=186059.97`.

## Troubleshooting

| Problem | Solution |
|---|---|
| The strip does not appear | Refresh the page and make sure the TradingView Watchlist widget is open. Also check the **Show in Watchlist** toggle in the extension popup. |
| The status is shown in red as disconnected | Check your internet connection or VPN. The socket connects to `ws.arzdigital.com`. If you use a VPN, enable TUN mode or WebSocket proxying. |
| The price is outdated | Wait a few seconds. Price messages usually arrive approximately once per second. |
| The socket works in Node.js but not in Chrome | In Chrome, the socket uses the TradingView page origin. The `test-ws.js` test showed that the server does not validate the origin, so this should not normally be a problem. If it occurs, open the tab console and inspect logs prefixed with `[USDT-Live]`. |
| The percentage change or font looks incorrect | The interface is localized for Persian users. Numbers are displayed using Persian digits, such as `۱۸۶٬۳۴۰`, with the Vazirmatn font. |

## Changing the Symbol

To display another asset, change `CHANNEL` in `content.js`, for example to a Bitcoin channel. Channel IDs can be found on the ArzDigital website.

## Notes

- This extension only displays price data; it does not send data anywhere.
- It requests the minimum required permission: `storage` only.
- If TradingView removes the Watchlist widget, only the price strip is hidden. The popup continues to display the price.
